Privacy policy

Last updated: 28 November 2026

clip-studio is a personal tool used only by its owner, for the owner's own YouTube channel.

What it accesses

With the owner's permission (Google OAuth), clip-studio uses these YouTube API Services scopes:

  • youtube.upload – to upload Shorts to the owner's channel;
  • youtube.readonly – to read the channel name and the statistics of its own videos;
  • yt-analytics.readonly – to read the channel's own analytics (for example average view percentage).

How the data is used and stored

  • Data is used only to publish the owner's videos and to decide which edits perform best.
  • Video statistics (views, likes, comments, retention) are stored in the owner's GitHub repository.
  • Access credentials are stored as encrypted GitHub Actions secrets and are never published.
  • No data is sold, shared with third parties or used for advertising.
  • No data about viewers or any other Google user is collected.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions. Stored statistics can be deleted by removing them from the repository.

Google and YouTube

clip-studio uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service, and data is handled under the Google Privacy Policy.
