clip-studio

An automated editor that turns gaming stream highlights into YouTube Shorts.

clip-studio is a personal automation tool run by its owner for a single YouTube channel. Once a day it:

  • finds popular public stream clips,
  • edits them into vertical Shorts (reframing, captions, highlights), crediting the original streamer,
  • uploads them to the owner's own YouTube channel through the YouTube Data API, and
  • reads that channel's public statistics and analytics to learn which edits work best.

It is not offered to other users and does not access anyone else's account.

Source code: github.com/K7694/clip-studio

clip-studio uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.
